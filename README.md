# bellaflow-scan

Doorverwijzing van scan.bellaflow.es naar https://bellaflow.es/#scan, de scan-app van Bella Flow
voor de telefoon in de winkel. GitHub Pages staat per repository één domein toe; de app zelf staat in
gruposoltura/bellaflow.

Instellingen: Pages op main / root, HTTPS afdwingen. DNS: `scan CNAME gruposoltura.github.io.`
